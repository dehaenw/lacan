LACAN Documentation
===================

LACAN (Leveraging Adjacent Co-occurrence of Atomic Neighborhoods) is a
statistical filter and generative cheminformatics toolkit for scoring, mutating,
and generating drug-like molecules using a model of bond environments learned
from ChEMBL.
